개념 따라가기

네 단계를 차례로 따라가면 "관측된 표본을 가장 그럴듯하게 만드는 모수가 최대가능도추정값"이라는 뜻이 그림으로 잡힙니다. 단계마다 직접 해 보기 과제와 확인 질문이 하나씩 있습니다.

1. 확률과 가능도 2. 곱에서 합으로 3. 꼭대기 찾기 4. 추정량의 성질

1단계 · 확률과 가능도

지수분포의 밀도 $f(x \mid \lambda) = \lambda e^{-\lambda x}$ 하나를 두 방향으로 봅니다. 왼쪽은 $\lambda$를 고정하고 $x$를 바꾼 곡선 — 어떤 값이 잘 나오는지 알려 주는 확률(밀도)입니다. 오른쪽은 관측값 $x = 1.2$를 고정하고 $\lambda$를 바꾼 곡선 — 어떤 모수가 이 관측을 잘 설명하는지 알려 주는 가능도 $L(\lambda \mid x)$입니다.

확률: λ 고정, x가 변한다

가능도: x = 1.2 고정, λ가 변한다

직접 해 보기λ를 움직여 왼쪽 그림에서 x = 1.2 위치의 높이(주황 점)가 가장 커지게 해 보세요. 그때 오른쪽 곡선의 어디에 있나요?
흔한 오해: "가능도는 λ가 참일 확률이다"
가능도는 λ에 대한 확률분포가 아닙니다. 오른쪽 곡선 아래 넓이를 λ에 대해 구하면 1이 아닙니다 (여기서는 1/x² ≈ 0.694).

2단계 · 곱에서 합으로

관측치가 여러 개면 가능도는 관측치별 밀도의 곱 $L(\mu) = \prod f(x_i \mid \mu)$입니다. 1보다 작은 수를 계속 곱하니 관측치를 더할 때마다 가능도가 급격히 작아집니다. 로그를 취하면 곱이 합 $\ell(\mu) = \sum \log f(x_i \mid \mu)$이 되어 다루기 쉬워집니다. (정규분포, $\sigma = 1$)

곱: 가능도 L(μ)

합: 로그가능도 ℓ(μ)

직접 해 보기관측치를 20개까지 더하며 왼쪽의 곱이 몇 자릿수까지 작아지는지 보세요. 오른쪽 막대의 합은 그 곱의 로그와 같습니다.

3단계 · 꼭대기 찾기

로그가능도 곡선의 기울기 $\ell'(\mu)$를 점수함수라고 부릅니다. 기울기가 양수면 오른쪽으로 갈수록 올라가고, 음수면 왼쪽이 오르막입니다. 꼭대기에서는 접선이 수평, 즉 $\ell'(\hat\mu) = 0$입니다. (정규분포, $\sigma = 1$, 관측치 10개)

직접 해 보기접선이 수평이 되도록 μ를 옮겨 보세요. 곡선을 끌어도 됩니다.

4단계 · 추정량의 성질

표본이 커질수록 상대가능도 $L(\mu)/L(\hat\mu)$ 곡선이 뾰족해집니다. 꼭대기의 곡률 $-\ell''(\hat\mu) = n/\sigma^2$이 정보량이고, 표준오차는 $1/\sqrt{n}$ 비율로 줄어듭니다. 같은 시드의 앞 n개를 쓰므로 n을 늘리면 $\hat\mu$가 참값 1 근처로 모여 갑니다.

직접 해 보기n을 5에서 200까지 늘려 보세요. 회색 곡선은 n = 5일 때입니다. 수백 번 반복하면 어떻게 될지는 반복 실험에서 확인하세요.
