# 가능도 실험실 화면 가이드

이 사이트가 보여 주려는 것은 한 문장입니다.

> **최대가능도추정값(θ̂)은 지금 가진 자료를 가장 그럴듯하게 설명하는 모수 값이다.**

화면마다 이 문장을 다른 방향에서 보여 줍니다. 아래는 각 화면이 **무엇을 보여 주는지**, **어떻게 읽는지**, **무엇을 해 보면 좋은지**를 정리한 것입니다.

사이트 주소: https://databetter25.github.io/mle-lab/

---

## 먼저: 색과 모양의 약속

모든 화면에서 같은 색·모양은 같은 대상을 뜻합니다. 이것만 기억하면 어느 그림이든 읽을 수 있습니다.

| 모양 | 색 | 뜻 |
| --- | --- | --- |
| ● 큰 원 | 주황 | **후보 θ** — 내가 슬라이더로 고른 "이 값이면 어떨까?" |
| ◆ 마름모 + 세로선 | 파랑 | **θ̂** — 자료를 가장 잘 설명하는 값 (정답) |
| ▲ 삼각형 + 긴 점선 | 초록 | **참값 θ₀** — 자료를 실제로 만들어 낸 값 (보통 현실에서는 모름) |
| ─ 가는 선 | 자주 | **접선** — 곡선의 기울기 (점수함수) |
| ● 작은 점 | 회색 | **관측치** — 뽑힌 자료 하나하나 |
| 굵은 테두리 | 주홍 | **경고** — 경계 해, 극단적으로 나쁜 기여 |

> θ̂(파랑)과 θ₀(초록)는 다릅니다. θ̂는 **자료에서 계산한 추정값**이고, θ₀는 **자료를 만든 진짜 값**입니다. 표본이 우연히 치우치면 둘이 어긋나고, 표본이 커질수록 가까워집니다.

## 1. 홈

**의미:** 사이트의 한 문장 정의와 학습 순서를 보여 주는 입구입니다.

- 오른쪽 움직이는 그림은 전체 아이디어의 요약입니다. 주황 점이 곡선을 따라 움직이다가 **꼭대기(파랑)에서 접선이 수평**이 됩니다. "가장 그럴듯한 값 = 곡선의 꼭대기 = 기울기가 0인 곳"이라는 뜻입니다.
- 아래 카드 네 개가 권장 순서입니다: **개념(왜) → 시뮬레이터(조작) → 유도 노트(수식) → 반복 실험(성질)**.

## 2. 개념 따라가기 (4단계 투어)

처음이라면 여기서 시작합니다. 단계마다 설명, 그림, **직접 해 보기** 과제, **확인 질문**이 하나씩 있습니다.

### 1단계 · 확률과 가능도

**의미:** 같은 식 f(x | θ)를 **두 방향으로** 본다는 것.

| 왼쪽 그림 | 오른쪽 그림 |
| --- | --- |
| θ를 고정하고 x를 바꿈 | x = 1.2를 고정하고 θ를 바꿈 |
| "이 모수에서는 어떤 값이 잘 나오나?" → **확률** | "이 관측을 가장 잘 설명하는 모수는?" → **가능도** |

- 슬라이더 λ를 움직이면 왼쪽 곡선 모양이 바뀌고, x = 1.2 위치의 높이(주황 점)가 오른쪽 곡선 위를 따라 움직입니다. 두 그림은 같은 숫자를 다른 축으로 본 것입니다.
- **해 보기:** 왼쪽에서 x = 1.2의 높이가 가장 커지는 λ를 찾으면, 그곳이 오른쪽 곡선의 꼭대기(λ̂ = 1/1.2 ≈ 0.833)입니다.
- **흔한 오해:** 가능도는 "θ가 참일 확률"이 아닙니다. 오른쪽 곡선 아래 넓이는 1이 아니라 약 0.694입니다.

### 2단계 · 곱에서 합으로

**의미:** 관측치가 여러 개면 가능도는 **관측치별 높이의 곱**이고, 로그를 취하면 **합**이 된다는 것.

- **왼쪽(곱):** "관측치 하나 더하기"를 누를 때마다 곱이 10⁻⁵, 10⁻¹⁰ … 식으로 급격히 작아집니다. 1보다 작은 수를 계속 곱하기 때문입니다. 컴퓨터로 곱을 직접 다루기 어려운 이유입니다.
- **오른쪽(합):** 같은 정보를 로그로 바꾸면 막대(log f)를 더하는 문제가 됩니다. 막대의 합 = 곱의 로그.
- 로그는 증가함수라서 **곱이 가장 큰 곳과 합이 가장 큰 곳이 같습니다.** 그래서 항상 로그가능도 ℓ(θ)로 계산합니다.

### 3단계 · 꼭대기 찾기

**의미:** 로그가능도 곡선의 **기울기(점수함수 ℓ′)**가 꼭대기로 가는 방향을 알려 준다는 것.

- 기울기 > 0 → 오른쪽이 오르막 → θ̂는 오른쪽에 있음
- 기울기 < 0 → 왼쪽이 오르막 → θ̂는 왼쪽에 있음
- 기울기 = 0 → 꼭대기 도착 → 그곳이 θ̂
- **해 보기:** 접선이 수평이 되게 μ를 옮기면 도착 메시지가 뜹니다. 이 값은 표본평균 x̄와 같습니다.

### 4단계 · 추정량의 성질

**의미:** 표본이 커지면 **가능도 곡선이 뾰족해지고** θ̂가 참값 근처로 모인다는 것.

- n을 5에서 200까지 늘리면 주황 곡선이 좁아집니다(회색은 n = 5일 때).
- 뾰족함 = **정보량**. 정보가 많을수록 추정이 정밀하고, 표준오차는 1/√n 비율로 줄어듭니다 (n을 4배 → 표준오차 1/2배).

## 3. 시뮬레이터 (핵심 화면)

**의미:** 분포를 골라 표본을 뽑고, 후보 θ를 직접 움직이며 **"이 값은 자료를 얼마나 잘 설명하나?"**를 세 그림과 숫자로 동시에 보는 곳입니다.

### 3-1. 위쪽: 분포 탭

분포마다 다른 교훈이 하나씩 있습니다.

| 탭 | 이 분포가 보여 주는 것 |
| --- | --- |
| 정규(μ) | 로그가능도가 **포물선**. MLE = 최소제곱 = x̄ |
| 베르누이 | 0/1 자료의 가능도. 모두 0이거나 모두 1이면 답이 **경계(0 또는 1)** |
| 이항 | 이항 n개 = 베르누이 n·m개와 곡선 모양이 같음 |
| 포아송 | 개수 자료, λ > 0 제약 |
| 지수 | 추정량이 **역수 모양** λ̂ = 1/x̄ |
| 정규(μ, σ²) | 모수가 둘이라 곡선 대신 **등고선**. σ̂²는 참값보다 작게 나오는 경향(편향) |
| 균등(0, θ) | **기울기가 0이 되는 곳이 없는데도** 최댓값이 있음 → 끝점 max xᵢ가 답 |

### 3-2. 왼쪽: 조작부

| 조작 | 의미 |
| --- | --- |
| 참값 θ₀ | 자료를 만들어 낼 "진짜" 모수. 바꾸면 새 표본을 뽑습니다. |
| 표본크기 n | 관측치 개수. **늘려도 이미 뽑은 점은 그대로** 남고 뒤에 점이 추가됩니다. |
| 난수 시드 · 새 표본(R) | 같은 시드 = 같은 표본. 수업에서 모두가 같은 자료를 볼 수 있습니다. |
| 후보 θ | 이 화면의 주인공. "이 값이면 자료가 얼마나 그럴듯한가?"를 시험하는 값 |
| 최댓값 찾기 | 컴퓨터가 꼭대기를 찾아가는 과정(뉴턴법)을 한 걸음씩 보여 줌 |
| θ̂로 이동 / θ̂ 주변 확대 | 꼭대기로 바로 가기 / 꼭대기 근처만 크게 보기 |
| 참값 숨기기 · 공개 | 처음엔 참값이 숨겨져 있음. 자료만 보고 추측한 뒤 공개해 비교 |
| 자료 직접 입력 | 내 자료를 붙여 넣거나, 그림을 눌러 점을 추가·삭제 (이상치 효과 관찰) |

### 3-3. 패널 A — 데이터와 후보 모형

**질문: "후보 θ라면, 각 관측치는 얼마나 나올 법한가?"**

- 회색 점 = 실제 관측치, 주황 곡선(또는 막대) = 후보 θ에서의 분포 모양.
- 각 점에서 곡선까지 그은 **주황 점선의 높이 f(xᵢ | θ)**가 그 점의 그럴듯함입니다. 높을수록 "이 모형에서 나올 법한 점".
- 후보 θ를 움직이면 곡선이 이동하면서 어떤 점은 높아지고 어떤 점은 낮아집니다.
- 이산 분포(베르누이·이항·포아송)는 막대 아래에 관측치를 점으로 쌓아 보여 줍니다.
- 점 위에 마우스를 올리면 그 점의 값과 f, log f가 뜨고, 패널 B의 같은 막대가 강조됩니다.

### 3-4. 패널 B — 기여분 원장

**질문: "각 관측치가 전체 점수에 얼마씩 보태나?"**

- 막대 하나 = 관측치 하나의 **log f(xᵢ | θ)**. 막대가 높을수록 그 점이 후보 θ를 지지합니다.
- 맨 오른쪽 굵은 막대 = **모든 막대의 합 ℓ(θ)** — 후보 θ의 총점입니다.
- **파랑 눈금** = θ̂에서의 값. 지금 막대가 파랑 눈금보다 낮으면 θ̂일 때보다 불리하다는 뜻입니다.
- θ를 움직이면 어떤 막대는 올라가고 어떤 막대는 내려가는 **줄다리기**가 보입니다. 총점이 가장 높아지는 지점이 θ̂입니다.
- 주홍 테두리 막대 = 후보 θ에서 거의 불가능한 점 (균등분포에서는 −∞).
- **곱으로 보면:** 막대를 더하는 대신 곱하면 값이 10⁻⁵⁰ 같은 수준으로 무너지는 모습을 보여 줍니다 → 로그를 쓰는 이유.

### 3-5. 패널 C — 가능도 곡선

**질문: "모든 후보 θ의 총점을 한 그림에 그리면?"**

- 검정 곡선 = 후보 θ마다의 총점 ℓ(θ). 패널 B의 오른쪽 막대를 모든 θ에 대해 이어 그린 것입니다.
- 주황 원 = 지금 후보, 파랑 마름모와 세로선 = θ̂(꼭대기), 초록 삼각형 = 참값.
- **자주 접선**과 "기울기 ℓ′(θ)" = 점수함수. 꼭대기에서 0이 되어 접선이 수평입니다.
- 곡선을 **직접 끌어서** θ를 옮길 수 있습니다.
- **상대가능도로 보기:** 세로축을 L(θ)/L(θ̂)(0~1)로 바꿔도 꼭대기 위치는 그대로입니다 → 로그를 써도 답이 같다는 증거.
- **곡률과 95% 가능도 구간:** 꼭대기가 뾰족할수록 표준오차가 작습니다. 파랑 굵은 선은 "θ̂만큼은 아니어도 꽤 그럴듯한 θ의 범위"(95% 가능도 구간)입니다.
- **최댓값 찾기:** 자주 화살표가 한 걸음씩 꼭대기로 가고, 아래 표에 걸음마다 θ와 기울기가 쌓입니다. 기울기가 0에 가까워지면 멈춥니다.
  - 베르누이(모두 1)처럼 **경계 해**면 끝으로 계속 다가갈 뿐 도달하지 못합니다.
  - 균등(0, θ)는 **max xᵢ에서 멈추고**, 기울기가 0이 아닌데도 거기가 최대인 이유를 설명합니다 (왼쪽은 가능도가 0인 불가능 영역).
- **정규(μ, σ²)**에서는 곡선 대신 **등고선 지도**가 됩니다. 산의 봉우리가 (μ̂, σ̂²)이고, 자주 화살표는 가장 가파른 오르막 방향입니다. 오른쪽 작은 그림은 μ를 μ̂에 고정하고 자른 단면입니다.

### 3-6. 수치 카드

**의미:** 그림을 숫자로 확인하는 곳입니다.

| 항목 | 뜻 |
| --- | --- |
| 대입식 (예: μ̂ = x̄ = 10.04 / 15 = 0.669) | θ̂ 공식에 실제 숫자를 넣은 계산 |
| 충분통계량 | 가능도를 정하는 데 필요한 요약값 (예: Σxᵢ, max xᵢ) |
| ℓ(θ), ℓ(θ̂) | 지금 후보의 총점, 최고 총점 |
| ℓ(θ̂) − ℓ(θ) | 지금 후보가 최고점보다 얼마나 낮은지 — **항상 0 이상** |
| 점수 ℓ′(θ) | 지금 위치의 기울기 — θ̂에서 0 |

- 경계 해일 때는 주홍 경고 상자가, 분포에 따라 **흔한 오해** 상자가 함께 나옵니다.
- **링크 복사:** 표본·후보·보기 옵션이 모두 주소에 담겨, 링크 하나로 같은 장면을 공유할 수 있습니다.

## 4. 유도 노트

**의미:** 시뮬레이터에서 본 것을 **수식으로 확인**하는 곳입니다. 모든 분포를 같은 다섯 단계로 풉니다.

| 단계 | 하는 일 | 그림에서는 |
| --- | --- | --- |
| 1 | 가능도 L(θ) = 관측치별 밀도의 곱을 쓴다 | 패널 A의 점선 높이, 패널 B "곱으로 보면" |
| 2 | 로그를 취해 합 ℓ(θ)로 바꾼다 | 패널 B의 막대 합 |
| 3 | 점수함수 ℓ′(θ) = 0으로 놓는다 | 패널 C의 접선이 수평인 곳 |
| 4 | θ에 대해 풀어 θ̂를 얻는다 | 수치 카드의 대입식 |
| 5 | 2계 도함수 < 0 (정말 꼭대기인지), 경계·제약 점검 | 패널 C의 곡률, 경계 해 경고 |

- 식 아래 **"그림에서 보기"**를 누르면 그 단계에 해당하는 패널이 강조된 시뮬레이터가 열립니다.
- 균등(0, θ)는 3단계에서 "기울기가 0이 되는 곳이 없다"로 막히고, 4단계에서 **함수 모양으로** 답을 찾는 예외입니다.

## 5. 반복 실험

**의미:** θ̂는 표본마다 달라지는 **확률변수**입니다. 표본을 수백 번 새로 뽑아 θ̂가 어떻게 흩어지는지 봅니다.

- **파랑 히스토그램** = R번(100/500/1000) 구한 θ̂들의 분포, 파랑 세로선 = 그 평균.
- **초록 세로선** = 참값 θ₀. 히스토그램이 이 선을 중심으로 모이면 추정이 잘 되는 것입니다.
- **검정 곡선** = 이론적 근사 N(θ₀, 1/(n·I(θ₀))). n이 크면 히스토그램이 이 종 모양에 맞아 갑니다 (점근정규성).
- 요약 숫자:
  - **편향** = θ̂ 평균 − 참값 (0에 가까우면 치우침 없음)
  - **표준편차** = θ̂가 흩어진 정도 ≈ 근사 표준오차
- **n = 10 → 50 → 200 비교:** 같은 가로축에 세 히스토그램을 나란히 그려 **n이 커질수록 폭이 좁아지는 것(일치성)**을 보여 줍니다.
- **정규(μ, σ²)**를 고르면 σ̂²(최대가능도추정량, 분모 n)와 s²(불편추정량, 분모 n−1)를 나란히 보여 줍니다. n = 5처럼 작을 때 σ̂²의 평균이 참값보다 뚜렷이 작습니다 → **MLE가 늘 불편한 것은 아니다.**
- 균등(0, θ)는 정규 근사 대신 θ̂ = max xᵢ의 정확한 분포를 겹칩니다. θ̂는 항상 θ보다 작습니다.

## 6. 도움말

사용법, 키보드 단축키, 세 패널 읽는 법, 용어집, 참고문헌이 있습니다.

**키보드 (시뮬레이터)**

| 키 | 동작 |
| --- | --- |
| ← / → | 후보 θ 한 칸 이동 |
| Shift + ← / → | 10칸 이동 |
| ↑ / ↓ | 정규(μ, σ²)에서 σ² 이동 (패널 C에 초점이 있을 때) |
| R | 새 표본 |
| 분포 탭에서 ← / → | 분포 바꾸기 |

---

## 한눈에 보는 흐름

```
[개념 따라가기]   왜 가능도를 쓰나?  확률 ↔ 가능도, 곱 → 합, 꼭대기 = 기울기 0
        ↓
[시뮬레이터]      직접 움직여 본다   A: 점별 그럴듯함 → B: 점수의 합 → C: 모든 θ의 총점 곡선
        ↓
[유도 노트]       수식으로 확인      L → ℓ → ℓ′ = 0 → θ̂ → 곡률·경계 점검
        ↓
[반복 실험]       추정량의 성질      모이는가(일치성)? 치우치는가(편향)? 얼마나 퍼지나(표준오차)?
```

## 흔한 오해 모음

| 오해 | 실제 | 확인하는 곳 |
| --- | --- | --- |
| 가능도는 θ가 참일 확률이다 | θ에 대해 적분해도 1이 아니다 | 개념 1단계 |
| 로그를 취하면 답이 달라진다 | 로그는 증가함수라 꼭대기 위치가 같다 | 패널 C의 ℓ ↔ L/L̂ 전환 |
| MLE는 늘 미분 = 0으로 구한다 | 균등(0, θ)는 끝점 max xᵢ가 답 | 균등 탭 + 최댓값 찾기 |
| MLE는 늘 불편추정량이다 | 정규의 σ̂²는 아래로 치우친다 | 반복 실험, 정규(μ, σ²) |
| 모두 0(또는 1)인 표본에서도 답이 내부에 있다 | p̂ = 0(또는 1), 경계 해 | 베르누이 탭 |
